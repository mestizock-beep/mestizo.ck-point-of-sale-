# 🌽 Mestizo Comedor & Bar - Punto de Venta (POS) & Inventarios

Sistema integral de Punto de Venta, control de inventarios sincronizados en tiempo real por recetas, arqueo y corte de caja, impresión de tickets térmicos (58mm/80mm) y envío de recibos por WhatsApp y SMS.

---

## 🚀 Cómo Ejecutar e Instalar en tu Computadora Local

### Requisitos Previos:
- [Node.js](https://nodejs.org/) instalado (versión 18 o superior).

### Pasos de Ejecución Local:

1. **Abrir la terminal** e ingresar a la carpeta del proyecto en Documentos:
   ```bash
   cd ~/Documents/mestizo-pos
   ```

2. **Instalar dependencias** (solo la primera vez):
   ```bash
   npm install
   ```

3. **Iniciar el Punto de Venta**:
   ```bash
   npm run dev
   ```
   *La aplicación estará lista en tu navegador local en: `http://localhost:3000`*
